# Car PNG assets

Drop transparent PNG files here using these **exact** filenames:

| File | Vehicle |
|------|---------|
| `apex-x1.png` | Apex X1 |
| `vortex-gt.png` | Vortex GT |
| `nova-r.png` | Nova R |
| `titan-s.png` | Titan S |
| `eclipse-x.png` | Eclipse X |
| `phantom-zero.png` | Phantom Zero (secret) |

## Tips

- Prefer **transparent background** (PNG with alpha)
- Side / 3⁄4 studio view works best
- Roughly **1200–2000px** wide is ideal (keep under ~1–2 MB each)
- Neutral / silver / white base paint tints more cleanly in the customizer

After adding files, reload the extension on `chrome://extensions` and open a new tab.
